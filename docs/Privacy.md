# Privacy Policy

**Last Updated:** September 15, 2026

## Overview

Socratic Coding Mentor is an open-source collection of prompt-based learning skills for coding, Data Structures and Algorithms, debugging, and software engineering. The project is published at the `socratic-coding-mentor` GitHub repository.

This policy applies to the project repository, its released skill files, and any official public listing maintained by the project maintainer. It does not replace the privacy policies of GitHub, OpenAI, Anthropic, Google, or any other AI service where you choose to use the project.

*Note: While this document outlines privacy practices, the use, modification, and distribution of the code and prompts within this project are governed strictly by the repository's open-source license (found in the `LICENSE` file in the root directory).*

## Data this project collects

The current skills-only release does **not** run a backend service, host a database, use cookies, use analytics, collect accounts, request API keys, or intentionally transmit your prompts, code, or personal information to the project maintainer.

The learning instructions are executed by the AI product you choose, such as ChatGPT/Codex, Claude, or Gemini. Those services process your conversations under their own terms and privacy policies. Review those policies before sharing personal, confidential, production, or customer data with an AI service.

## GitHub data

The repository and its releases are public. Anything you intentionally submit publicly through GitHub—such as an issue, pull request, discussion, comment, commit, profile information, or email address included in a commit—may be visible to other visitors.

Do not put passwords, API keys, access tokens, personal data, customer data, private source code, or security-sensitive information in a public GitHub issue, pull request, or discussion.

GitHub independently processes information used to operate its service. See the [GitHub General Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement).

## Third-party AI platforms

This project may be distributed through or used with third-party AI platforms. The project maintainer does not control those platforms' storage, retention, training, account, telemetry, or sharing settings.

Before using Socratic Coding Mentor on a third-party platform:

- review the platform's privacy and data-control settings;
- use its approved account and workspace for work data;
- do not paste secrets or confidential code unless you are authorized to share it; and
- understand that a public Gem, shared skill, or public chat link can expose its instructions and any attached files to the people who receive access.

Useful platform privacy resources include the [OpenAI privacy policy](https://openai.com/policies/privacy-policy/), [Claude privacy information](https://privacy.claude.com/), and the [Gemini Apps Privacy Hub](https://support.google.com/gemini/answer/13594961?hl=en).

## Voluntary contact

If you open a GitHub issue, pull request, or discussion, the information you choose to include is used only to review, respond to, and maintain the project. Do not include sensitive information.

The project does not sell personal information.

## Changes to this policy

This policy may be updated when the project adds a website, analytics, a backend service, authentication, an MCP server, or another feature that changes how data is handled. Material changes will be made in this file and committed to the public repository.
